Marking codes for teachers: a ready-to-use list

Why marking codes help

Marking codes are short symbols you write in a student's work instead of a full comment, such as Sp for a spelling mistake or // for a new paragraph. They save you writing the same note over and over, and they leave the thinking to the student: a code points to the problem, and the student has to work out the fix.

They work best for things that come up again and again, especially literacy (spelling, punctuation and grammar) and simple skills like adding evidence. Save your written comments for the feedback that needs real thought.

A ready-to-use list

Here are 15 codes that cover most of what comes up in written work across subjects. Use them as they are, or adapt them to match your school's literacy policy.

CodeWhat it means for the student
SpSpelling mistake: check and correct this word.
PPunctuation error.
CCapital letter needed (or used wrongly).
GGrammar: re-read this sentence and correct it.
//Start a new paragraph here.
WWWrong word: choose a more accurate word.
?Meaning is unclear: rewrite this more clearly.
^Something is missing here.
TTense error.
EvAdd evidence or an example here.
ExExplain this point further.
QLink back to the question.
RRepetition: vary your wording.
✓Good point.
✓✓Excellent point.

Keep it short. Fifteen codes is plenty. If students need a key to decode every other mark, the codes are slowing them down rather than helping.

How to introduce them to a class

  1. Share the key. Stick a copy in exercise books, put it on the wall, or pin it in Google Classroom.
  2. Model it once. Show a marked paragraph on the board and correct it together, so students see what each code asks them to do.
  3. Give time to respond. Codes only work if students act on them. Build in a few minutes of improvement time when you hand work back.
  4. Stay consistent. Use the same codes all year, and ideally the same ones across your department, so students don't have to relearn them.

Using marking codes in Google Docs

Marking on screen? There are three easy ways to use codes in a Google Doc:

  • Type them inline. Put the code in square brackets, like [Sp], straight after the mistake. Use Suggesting mode if you don't want to change the student's text.
  • Use comments. Highlight the word and add a comment containing just the code. Students can resolve each comment once they've fixed it.
  • Use an add-on. Our free add-on, Remark, puts these 15 codes one click away, inserts them as you mark, and adds a key to the end of the document automatically, so students always know what each one means.

Turn codes into improvement time

Codes fit naturally with DIRT (Directed Improvement and Reflection Time), where students spend lesson time responding to feedback. A few tasks that work well with codes:

  • Correct every spelling marked Sp, then write each word out correctly three times.
  • Find a point marked Ev and add a piece of evidence to support it.
  • Rewrite one paragraph marked Ex, adding two sentences that explain the point further.
  • Fix every // by deciding where each new paragraph should start, and say why.

Questions people ask

What are marking codes?

Marking codes are short symbols teachers write in students' work instead of full comments, such as Sp for a spelling mistake or // for a new paragraph. A shared key tells students what each code means and what to do about it.

How many marking codes should a school use?

Fewer is better. Around 10 to 15 codes covers most literacy and writing issues without students needing to look up every mark. Using the same set across a department or school helps students remember them.

Do marking codes work for primary as well as secondary?

Yes, though younger pupils usually do better with fewer, simpler codes and symbols, introduced a few at a time. Many primary schools pair codes with symbols or colours.

Can I use marking codes in Google Classroom?

Yes. Type codes in square brackets in the student's Google Doc, add them as comments, or use an add-on like Remark that inserts them in one click and adds the key automatically.
